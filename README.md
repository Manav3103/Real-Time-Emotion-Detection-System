# Real-Time-Emotion-Detection-System
This project performs real-time emotion detection using your system’s camera. It detects faces in live video using Haarcascade Frontal Face Classifier and then predicts the emotion using DeepFace.

![original-3d90fb09f5268a362e6ee1c01e0bbb48](https://github.com/user-attachments/assets/ea2f2eb2-6943-4b2b-a168-5946f5956b6c)

# Features
📸 Real-time webcam video capture
😃 Emotion prediction (happy, sad, angry, fear, surprise, neutral, etc.)
🧠 Uses DeepFace for emotion analysis
🟦 Face detection via OpenCV Haarcascade
🔴 Emotion label displayed on top of the detected face
⏳ Press 'q' to exit the app


# Tech Stack
Python  
OpenCV  
DeepFace


# How to Run

pip install opencv-python
pip install deepface

# Run the script:
python app-2.py

**Make sure your webcam is connected and accessible.**
